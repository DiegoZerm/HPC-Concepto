# HPC Concepto

## ¿Qué es HPC (High Performance Computing)?

El **HPC** (High Performance Computing) o computación de alto rendimiento consiste en agrupar la potencia de varios ordenadores para trabajar como un solo sistema extremadamente rápido. Se usa para resolver problemas complejos que tardarían años en un solo PC.

### ¿Para qué se usa?
- Simulaciones climáticas y meteorológicas
- Investigación científica (física, química, biología)
- Ingeniería y diseño (aeronáutica, automotriz)
- Descubrimiento de fármacos y modelado molecular
- Análisis de Big Data

### Características clave:
- **Parallelismo**: Muchos procesadores (CPUs/GPUs) trabajando simultáneamente
- **Velocidad**: Teraflops o petaflops de capacidad de cálculo
- **Clusters**: Grupos de servidores conectados que funcionan como uno solo
